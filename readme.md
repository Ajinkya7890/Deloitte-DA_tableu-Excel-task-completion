# Deloitte Data Analytics Job Simulation – Tableau & Excel Tasks

## Overview

This repository contains the solutions completed as part of the **Deloitte Data Analytics Job Simulation** on Forage. The project focuses on data analysis, visualization, and business insight generation using **Tableau** and **Microsoft Excel**.

## Tasks Completed

### Task 1: Tableau Dashboard Development

* Analyzed Daikibo factory telemetry data.
* Created interactive visualizations in Tableau.
* Identified patterns and insights from operational data.
* Developed a dashboard to support business decision-making.

### Task 2: Equality Analysis in Excel

* Analyzed employee compensation equality data across factories and job roles.
* Created an **Equality Class** column based on Equality Score values.
* Classified records into:

  * **Fair** (Score between -10 and 10)
  * **Unfair** (Score between -20 and -11, or 11 and 20)
  * **Highly Discriminative** (Score less than -20 or greater than 20)

## Files Included

* `daikibo-telemetry-data.json` – Telemetry dataset used for Tableau analysis.
* `Dashboard task.twb` – Tableau workbook containing the completed dashboard.
* `Task 5 Equality Table_Edited.xlsx` – Excel file containing equality classification results.
